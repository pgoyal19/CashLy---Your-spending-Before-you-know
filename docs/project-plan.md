# CashLy Project Plan

## Goal
Build a complete academic minor project for personal finance tracking with AI-powered spending insights and forecasting.

## Primary Modules

1. Authentication and user onboarding
2. Dashboard with spending summary and predictive insights
3. Expense tracking with category management
4. Budget and goal planning
5. AI-powered assistant and recommendations
6. Receipt OCR and document ingestion

## Current Status

- Frontend scaffolded with React + Vite
- Python FastAPI backend operational
- Core auth, summary, dashboard, and assistant routes implemented
- AI service skeleton exists with rule-based categorization and forecasting endpoints
- Docker build definitions aligned to the Python + React stack

## Next Enhancements

- Add persistence layer with SQLite/PostgreSQL
- Add protected user routes and JWT validation
- Expand front-end page navigation and forms
- Improve AI service intelligence and forecasting logic
- Add OCR and receipt upload flow
